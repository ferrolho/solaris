# Solaris

Interactive 3D solar system simulation built with [Three.js](https://threejs.org/).

Navigate the solar system, view textured planets with realistic positions, and explore from the Sun to Pluto.

## Controls

| Input | Action |
|-------|--------|
| Left mouse | Orbit camera |
| Right mouse | Pan camera |
| Scroll wheel | Zoom |
| Keys 0-9 | Teleport to Sun, Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune, Pluto |
| Gamepad right stick | Rotate camera |

## Getting Started

```bash
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.

## Build

```bash
npm run build
npm run preview
```
